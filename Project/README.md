**Мета роботи:** Ознайомитись із механізмами міжпроцесної взаємодії (IPC) в ОС Linux за допомогою іменованих каналів (FIFO). Розробити архітектуру «клієнт-сервер» для двосторонньої передачі повідомлень та їх логування.

**Опис реалізації:** Створено дві незалежні програми (`server.c` та `client.c`). Для зв'язку використовуються два іменовані канали у директорії `/tmp`: `fifo_c2s` (від клієнта до сервера) та `fifo_s2c` (від сервера до клієнта). Сервер ініціалізує канали, очікує повідомлення від клієнта, записує його у файл `server.log`, надсилає підтвердження клієнту та очищає ресурси. Клієнт надсилає текст, переданий через аргументи командного рядка, очікує та виводить отриману відповідь.

**Використані системні виклики:**

* `mkfifo()` — створення спеціальних файлів іменованих каналів. 
* `open()` — відкриття каналів та створення/відкриття файлу логів. 
* `read()` — зчитування даних з каналу у буфер програми. 
* `write()` — запис даних у канал та лог-файл. 
* `close()` — закриття файлових дескрипторів. 
* `unlink()` — видалення файлів каналів з тимчасової файлової системи.

**Приклад запуску:**

Компілюємо файли

```bash 
gcc server.c \-o server

gcc client.c \-o client

```

В першому терміналі запускаємо сервер

```bash

./server

```

В другому терміналі запускаємо клієнта з повідомленням

```bash

./client “Повідомлення”

```
